# SWOT-analysis-quiz
Interactive SWOT Analysis Quiz built using HTML, CSS, and JavaScript to generate a personalized SWOT profile based on user responses.

##live URL
https://vharini-cse.github.io/SWOT-analysis-quiz/

### Features
- Interactive SWOT-based assessment
- Identifies user strengths and weaknesses
- Highlights potential opportunities and threats
- Calculates and displays an overall score
- Provides a personalized analysis result
- Simple and responsive user interface

### Technologies Used
- HTML
- CSS
- JavaScript

### Purpose
The project is designed to help students gain a better understanding of their skills, areas for improvement, and possible growth opportunities through an interactive SWOT analysis.
